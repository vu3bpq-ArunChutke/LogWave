# LogWave
Amateur Radio Logging Software
About the Project
LogWave was developed as a personal amateur radio logging application with a focus on:

    Simple operation
    Fast QSO entry
    Clear and readable interface
    Easy log maintenance


LogWave is a Windows-based Amateur Radio logging application developed to provide a simple, fast, and user-friendly solution for recording and managing QSOs.
The software was developed by Arun as a personal logging project with emphasis on usability, quick data entry, readable user interface elements, and efficient log management.
Features

**QSO Management**

   Create, edit, and delete QSO records
   Fast data entry workflow
   Search and filter logged contacts
   Sort records by any field
   Automatic timestamp handling
   
**Callsign Lookup**

    Automatic retrieval of:
    Operator Name
    QTH / Location
    Country information
    
**Logging Functions**

        Add new QSOs
        Edit existing QSOs
        Delete QSOs
        Search logged contacts
        View all records in a sortable table
**Data Storage**

    Local database storage
    Persistent log records
    Easy backup and restoration of log data
    
**Requirements**

    Windows 10 or Windows 11
    Python 3.10 or later
